Technologie, postup a hranice

Python 3.13 standardní knihovna, SQLite WAL, parametrizované SQL, skutečné HTTP mezi dvěma loopback službami, HTML/CSS/JS. API klíč ani AI nejsou potřeba. Přesná částka se normalizuje přes Decimal do haléřů, jméno a e-mail se sjednotí. Transport počítá nejvýše tři pokusy v cyklu, 2/4sekundové odklady a Retry-After do 60 sekund. Trvalé odmítnutí a neplatný vstup jdou do fronty chyb.

Fronta i CRM uchovávají data v oddělených SQLite souborech. ID události s jiným obsahem je konflikt; CRM kontroluje tentýž idempotency klíč. Po přerušení workeru se nárok uvolní po 10 sekundách. Replay zachová ID, obsah i historii, nejvýše dva ruční cykly. Náhled nic nezapisuje.

Pouze fiktivní data. Není zde autentizace, podpis webhooku, skutečný CRM konektor, SSO, produkční monitoring ani neomezená fronta. Limit 1 000 běhů. Externí adresu nelze zadat uživatelským JSON. Před firmou přidat ověřování identity/zdroje, řízení tajemství, retenční pravidla a monitoring.
